SPARQL (SPARQL Protocol and RDF Query Language) is a query language for retrieving and manipulating data stored in the Resource Description Framework (RDF) format. It was standardized by the W3C and is recognized as one of the key technologies of the semantic web. SPARQL 1.0 became a W3C recommendation on 15 January 2008, and SPARQL 1.1 followed in March 2013. A SPARQL query matches triple patterns against an RDF graph. The language defines four query forms for reading data: SELECT, CONSTRUCT, ASK, and DESCRIBE.
